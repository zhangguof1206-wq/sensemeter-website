# About page photography sources

The About page uses four documentary stock photographs. None of these files is reused from the homepage application section or an application detail page. The photographs illustrate representative industrial environments and do not depict SenseMeter or SINOETM TECH LTD facilities, employees or customer projects.

All four photographs are supplied under the Pexels License. Pexels permits commercial website use without required attribution. The files are stored locally so the production page does not depend on third-party image hosting.
