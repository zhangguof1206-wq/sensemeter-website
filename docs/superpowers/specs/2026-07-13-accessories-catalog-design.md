# SenseMeter 配件目录设计

## 目标

在首页增加配件入口，并建立四个配件大类页和二十四个配件详情页。页面面向已经了解仪器和工况的采购人员，重点传达可供应、可定制、可配套选型和可提供售后，不堆砌长篇产品资料。

## 分类

1. `sensor-protection`：探头保护罩与传感器外壳，6 个配件。
2. `sintered-filter-elements`：烧结滤芯与过滤元件，6 个配件。
3. `sample-gas-filters`：采样气体过滤器，6 个配件。
4. `flow-control-accessories`：采样、限流与气路配套件，6 个配件。

## 页面层级

- 首页配件区：四张大类卡片，链接到大类页。
- `/accessories`：配件总览。
- `/accessories/[category]`：大类说明、六个特色配件、定制与售后说明。
- `/accessories/[category]/[slug]`：配件结构、适用仪器、选型信息、定制范围、售后和 RFQ。
- 英文页面统一增加 `/en` 前缀，并保留 canonical 与 hreflang。

## 内容原则

- 不展示恒歌或 HENGKO 品牌名称、标识和联系信息。
- 不宣称固定库存、固定交期或未经确认的性能保证。
- 参数只保留采购识别所需的材质、结构、接口、精度/孔径、压力/温度和适用气体等选型项。
- 所有页面使用“SenseMeter 可供应”“支持按工况确认”“实际规格以确认结果为准”等诚实表述。
- 页面不显示价格，所有成交动作统一进入 RFQ。

## 图片原则

- 每个配件使用真实产品结构图作为基础。
- 去除原网站品牌标识和营销文字，统一为浅灰工业背景。
- 产品图不添加任何品牌标识；SenseMeter 品牌只保留在网页页眉和文案中。
- 页面标注图片为结构示意，实际外观和规格以确认结果为准。

## 数据与组件

- 配件类型、分类和产品分别存放，四类产品拆分为四个数据文件。
- 首页区、大类页和详情页使用独立组件，不继续扩大 `src/components/site.tsx`。
- sitemap 和 Yandex URL 清单由同一配件数据生成，避免遗漏。

## 验收

- 四类、每类六个，共二十四个配件数据完整且 slug 唯一。
- 俄语和英语的总览、大类和详情路由全部可构建。
- 首页、桌面和手机端无重叠或横向溢出。
- 图片中不出现恒歌/HENGKO 或其他品牌标识。
- SEO、i18n、Yandex URL、类型检查和生产构建通过。
