# MDM300 三图轮播及下载按钮反馈

**目标：** 只更新 MDM300 俄英样板的图片区域及用户标出的文档下载按钮。其他页面、参数、SEO、表单和统计不变，不推送、不发布。

## 已确认设计

- 基于现有 MDM300 图片生成三张白底展示图：双机、普通型及本安型。不虚构背面或接口。
- 生成图明确作为 AI 辅助展示图，不冒充新增实拍；保留附件不是默认标配的说明。
- 独立客户端轮播组件，每 3000 毫秒循环切换。使用固定画幅，不随图片或按钮状态改变尺寸。
- 提供缩略图、上一张、下一张及播放/暂停图标，俄英可访问名称和工具提示完整。
- 手动选择图片会暂停自动播放；鼠标悬停、页面隐藏及系统减少动态效果设置也会停止自动切换。
- 文档区 PDF 按钮使用现有品牌红底白字，首屏 PDF 按钮保持描边样式。
