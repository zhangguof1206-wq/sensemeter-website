# 首页按钮层级与入场动画优化计划

## 目标

- 品牌区域取消重复的文字入口，改用整行悬停与聚焦反馈；配件和应用区域使用清晰可识别的操作按钮。
- 将配件图片和名称分成独立区域，避免文字与图片交错。
- 使用一次性滚动入场动画建立阅读顺序，并兼容系统的“减少动态效果”设置。
- 保持现有工业编辑式布局、动态首页背景和所有网站内容不变。

## 实施步骤

1. 先补充自动检查，覆盖按钮样式、配件图文分区、滚动观察器和无障碍降级。
2. 调整三个首页区块的操作入口层级，并重构配件单元的图文结构。
3. 新增独立的客户端滚动观察器，避免给服务端页面引入不必要的交互状态。
4. 检查桌面端和移动端截图、横向溢出、类型检查与生产构建。
5. 保持本地预览运行，并提交一笔完整的中文提交记录。

## 验收标准

- 品牌条目通过轻微抬升、底色和产品图位移表达可点击；配件与应用按钮和普通正文有明确差异。
- 配件图片区和名称区由分隔线划分，最长标题不会覆盖图片。
- 页面区块进入视口时仅播放一次轻微上移淡入动画。
- 开启“减少动态效果”时不隐藏内容，也不播放入场动画。
- 390px 与 1440px 视口无横向溢出，构建和现有检查全部通过。
